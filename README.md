## Current decision

Recommended starting point: **Are customer complaints associated with later telecom churn?** The UCI Iranian Churn dataset has 3,150 customer records according to its publisher. It supports a focused EDA and chi-square test with a clear business interpretation.

For a more unusual subject, consider **Do two rice varieties differ in grain shape?**

The student chooses the topic before dataset inspection and implementation. The next session will inspect actual rows, define each variable, verify usable observation counts, and settle one primary hypothesis before running tests.
